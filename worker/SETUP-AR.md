# نظام الطلبات وعروض الأسعار — دليل التشغيل

هذا المجلد يحوّل نموذج «اطلب عرض سعر» في الموقع من رسالة `mailto` (تعتمد على جهاز الزائر وتضيع غالباً)
إلى **نظام حقيقي**: يستقبل الطلب، يحفظه، يُشعرك فوراً، يردّ على الزبون آلياً، ويمنحك **لوحة تحكم**
و**مولّد عروض أسعار** بأرقام متسلسلة ورابط خاص لكل زبون.

---

## ١. ما الذي يعمل الآن

| المسار | ماذا يفعل |
|---|---|
| `POST /api/rfq` | يستقبل النموذج من الموقع، يتحقق منه، يحفظه في قاعدة البيانات برقم مرجعي `RFQ-2026-0001` |
| — | يرسل لك إشعاراً فورياً على **تلغرام** + **بريد** |
| — | يرسل للزبون **رد استلام آلياً** بلغته (عربي/إنجليزي) |
| `/admin` | لوحة الطلبات: بحث، فلترة بالحالة، إحصاءات، ملاحظات داخلية |
| `/admin/quote/new` | **بنّاء عرض السعر**: بنود، Incoterm، ميناء، شروط دفع، صلاحية، شحن، خصم، إجمالي فوري |
| `/q/:token` | صفحة العرض للزبون: رابط خاص، عربي/إنجليزي، **طباعة PDF (A4)**، وأزرار **قبول / اعتذار** |
| — | عند رد الزبون: إشعار فوري لك، وتتحدّث حالة الطلب تلقائياً إلى «تم البيع» أو «خسرنا» |
| `/admin/export.csv` | تصدير كل الطلبات إلى Excel |

الحماية: مصيدة سبام مخفية، تحديد معدّل (٥ طلبات / ١٥ دقيقة لكل IP)، جلسة موقّعة بـ HMAC،
كوكي `HttpOnly`، ولا فهرسة لصفحات اللوحة أو العروض من محركات البحث.

---

## ٢. النشر — خطوة بخطوة (مرّة واحدة)

### المتطلبات
- حساب **Cloudflare** مجاني.
- **Node.js** مثبّت.
- الدومين `alsultan-zahdi-dates.com` مُدار عبر Cloudflare (أو أضِفه إليها) إذا أردت نطاقاً فرعياً جميلاً.

### الخطوات

**١) تسجيل الدخول إلى Cloudflare**

```bash
cd worker && npm install && npx wrangler login
```

**٢) إنشاء قاعدة البيانات**

```bash
npx wrangler d1 create alsultan
```

انسخ `database_id` الظاهر، وضعه في `wrangler.toml` مكان `REPLACE_WITH_D1_DATABASE_ID`.

**٣) إنشاء الجداول**

```bash
npx wrangler d1 execute alsultan --remote --file=./schema.sql
```

**٤) ضبط الأسرار** (لا تُكتب في أي ملف)

```bash
npx wrangler secret put ADMIN_PASSWORD
```

```bash
npx wrangler secret put SESSION_SECRET
```

> `ADMIN_PASSWORD` = كلمة مرور لوحة التحكم (اجعلها قوية).
> `SESSION_SECRET` = أي نص عشوائي طويل (٤٠ حرفاً فأكثر) — يوقّع جلسة الدخول.

**٥) النشر**

```bash
npx wrangler deploy
```

**٦) ربط النطاق الفرعي**
في لوحة Cloudflare → Workers & Pages → `alsultan-rfq` → Settings → **Domains & Routes** → Add
**Custom Domain** → `rfq.alsultan-zahdi-dates.com`.

> **الموقع على Vercel والدومين على Cloudflare — لا تعارض.**
> الجذر `alsultan-zahdi-dates.com` و`www` يبقيان مشيرَين إلى Vercel كما هما.
> النطاق الفرعي `rfq.` وحده هو الذي يذهب إلى الـ Worker، وCloudflare تنشئ سجلّه تلقائياً
> عند إضافة الـ Custom Domain. لا تلمس سجلات Vercel.

**٧) مطابقة الإعدادات**
- في `wrangler.toml`: تأكد أن `PUBLIC_BASE_URL` = `https://rfq.alsultan-zahdi-dates.com`
  وأن `ALLOWED_ORIGINS` يحوي نطاق الموقع الفعلي (مضبوط مسبقاً، ويشمل `https://*.vercel.app`
  حتى تعمل معاينات Vercel المؤقتة أيضاً).
- في `index.html` (السطر ٦٤٢): `RFQ_ENDPOINT` = `https://rfq.alsultan-zahdi-dates.com/api/rfq`.
- أعد النشر بعد أي تعديل على `wrangler.toml`:

```bash
npx wrangler deploy
```

**٨) رفع الصفحة المعدّلة إلى Vercel**
ادفع الفرع إلى GitHub وستنشره Vercel تلقائياً، أو من جذر المشروع:

```bash
npx vercel --prod
```

الآن افتح `https://rfq.alsultan-zahdi-dates.com/admin` وادخل بكلمة المرور.

## ٣. الإشعارات (اختيارية لكن موصى بها بشدة)

### تلغرام — الإشعار الفوري (الأسرع والأسهل)
1. في تلغرام: افتح **@BotFather** → `/newbot` → اختر اسماً → ستحصل على **التوكن**.
2. أرسل أي رسالة للبوت الجديد، ثم افتح في المتصفح:
   `https://api.telegram.org/bot<التوكن>/getUpdates` وخذ الرقم من `"chat":{"id":...}`.
3. اضبط السرّين:

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
```

```bash
npx wrangler secret put TELEGRAM_CHAT_ID
```

> لإيصال الإشعار لعدة أشخاص: أنشئ مجموعة، أضِف البوت إليها، واستخدم معرّف المجموعة (يبدأ بـ `-`).

### البريد — عبر Resend
1. سجّل في [resend.com](https://resend.com) (الباقة المجانية تكفي: ٣٬٠٠٠ رسالة شهرياً).
2. أضف الدومين **الذي سترسل منه** وفعّل سجلات DNS التي يطلبها (SPF/DKIM) — **ضرورية** حتى لا تدخل الرسائل في السبام.

   > **انتبه:** بريدك `info@alsultan-dates.com` على دومين مختلف عن دومين الموقع
   > `alsultan-zahdi-dates.com`. للإرسال باسم `info@alsultan-dates.com` يجب أن تملك تحكّماً بـ DNS
   > الخاص بـ `alsultan-dates.com` وتوثّقه في Resend.
   > إن لم يكن تحت يدك، فالحل: وثّق `alsultan-zahdi-dates.com` واجعل
   > `MAIL_FROM = "Alsultan Dates <no-reply@alsultan-zahdi-dates.com>"`
   > مع إبقاء `SALES_EMAIL` و`MAIL_TO` على `info@alsultan-dates.com` — فتصلك الردود على بريدك المعتاد.

3. اضبط المفتاح:

```bash
npx wrangler secret put RESEND_API_KEY
```

4. تأكد في `wrangler.toml` أن `MAIL_FROM` بريد على الدومين الموثّق، و`MAIL_TO` بريدك الذي تتابعه.

> إن لم تضبط هذه الأسرار، يبقى النظام يعمل ويحفظ كل الطلبات — لكن بلا إشعارات ولا رد آلي.

### واتساب
حقل `SALES_WHATSAPP` في `wrangler.toml` للرقم الظاهر للزبائن. أما إرسال العروض عبر واتساب فيتم
بزر جاهز داخل اللوحة يفتح المحادثة مع الزبون ونص العرض ورابطه مكتوبَين مسبقاً (بدون رسوم واجهة برمجية).

## ٤. طريقة العمل اليومية

1. **يصلك إشعار** على تلغرام/البريد لحظة إرسال الزبون للنموذج.
2. تفتح `/admin` → الطلب موجود بحالة **جديد**.
3. تفتح الطلب → تراجع التفاصيل → تراسل الزبون عند الحاجة (زرّا بريد وواتساب جاهزان) → تغيّر الحالة إلى **تم التواصل**.
4. تضغط **«+ إنشاء عرض سعر»**:
   - البنود تُملأ من الطلب، تضيف السعر والكمية والوحدة،
   - تختار Incoterm والميناء وشروط الدفع ومدة التجهيز وصلاحية العرض،
   - الإجمالي يُحسب أمامك مباشرة.
5. تحفظ → يصبح للعرض رقم `Q-2026-0001` ورابط خاص.
6. تُرسله: **بزر البريد** (يصل للزبون بريد مصمّم فيه الرابط) أو **بزر واتساب** أو بنسخ الرابط.
7. الزبون يفتح الرابط → يقرأ العرض بلغته → **يطبعه PDF** → ويضغط **قبول** أو **اعتذار**.
8. يصلك إشعار برده فوراً، وتتحدّث حالة الطلب تلقائياً.

> **PDF:** زر «طباعة / حفظ PDF» في صفحة العرض يستخدم طباعة المتصفح بتنسيق A4 مضبوط
> (خلفية بيضاء، بلا أزرار). هذا يعطي عربية سليمة الاتجاه ١٠٠٪ — وهو ما تفشل فيه أغلب مكتبات PDF.

## ٥. الصيانة

**نسخة احتياطية للبيانات:**

```bash
npx wrangler d1 export alsultan --remote --output=backup.sql
```

**استعراض سريع للطلبات من الطرفية:**

```bash
npx wrangler d1 execute alsultan --remote --command "SELECT ref,company,country,status FROM requests ORDER BY id DESC LIMIT 20"
```

**تشغيل محلي للتجربة:** انسخ `.dev.vars.example` إلى `.dev.vars`، ثم:

```bash
npx wrangler d1 execute alsultan --local --file=./schema.sql
```

```bash
npx wrangler dev
```

## ٦. حلّ المشاكل

| العَرَض | السبب الغالب | الحل |
|---|---|---|
| النموذج يقول «تعذّر إرسال الطلب» | نطاق الموقع غير مذكور في `ALLOWED_ORIGINS` | أضِفه في `wrangler.toml` ثم `npx wrangler deploy` |
| لا تصل رسائل بريد | الدومين غير موثّق في Resend، أو `MAIL_FROM` على دومين آخر | وثّق الدومين واضبط `MAIL_FROM` عليه |
| لا يصل إشعار تلغرام | لم تراسل البوت أولاً، أو `CHAT_ID` خطأ | راسل البوت ثم أعد قراءة `getUpdates` |
| «كلمة المرور غير صحيحة» رغم صحتها | لم يُضبط `ADMIN_PASSWORD` بعد آخر نشر | `npx wrangler secret put ADMIN_PASSWORD` |
| طلبات وهمية / سبام | نادر بسبب المصيدة وتحديد المعدّل | قلّل `limit` في `rateLimit` داخل `src/index.js` |

**التكلفة:** ضمن الباقة المجانية في Cloudflare (‏١٠٠ ألف طلب يومياً و‏٥ ملايين قراءة من D1) —
أي **صفر تقريباً** لحجم عمل شركة تصدير.
